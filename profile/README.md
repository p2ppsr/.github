# Project Babbage

We build practical BSV applications, wallet integrations and developer tools.

## Start here

- **Build an application:** [Project Babbage docs](https://docs.projectbabbage.com/docs/quickstarts/your-first-bsv-app) and the current [BSV TypeScript SDK](https://github.com/bsv-blockchain/ts-sdk).
- **Use source-grounded AI:** [BitGenius developer API](https://developer.bitgenius.net/). The account-key API is live in public preview with a documented text and client function-tool subset.
- **Learn by building:** [Metanet Academy's free build guide](https://metanetacademy.com/build).
- **Install a wallet:** [Metanet Client downloads](https://github.com/p2ppsr/metanet-client-downloads).
- **Discuss a paid integration or team training:** [Contact Project Babbage](https://projectbabbage.com/contact).
